# ASC 855: Subsequent Events

> Critical guidance for evaluating and disclosing events occurring after the balance sheet date.

## Overview

ASC 855 establishes standards for accounting for and disclosure of events that occur after the balance sheet date but before financial statements are issued (or available to be issued). Proper identification and treatment of subsequent events is essential for ensuring financial statements reflect all relevant information available at the time of issuance.

**Core Principle:**
> "An entity shall recognize in the financial statements the effects of all subsequent events that provide additional evidence about conditions that existed at the date of the balance sheet, and disclose subsequent events that provide evidence about conditions that arose after the balance sheet date."

---

## Scope

### Applies To:
- All entities preparing financial statements in conformity with GAAP
- Accounting for and disclosure of subsequent events
- Reissued financial statements

### Does NOT Apply To:
- Subsequent events related to contingencies already covered by ASC 450
- Events occurring after reissuance (only original subsequent events window)
- Interim financial statements (follow same principles but different dates)

---

## Key Definitions

| Term | Definition |
|------|------------|
| **Subsequent Events** | Events or transactions occurring after the balance sheet date |
| **Recognized Subsequent Event** | Event providing evidence of conditions that existed at balance sheet date |
| **Nonrecognized Subsequent Event** | Event providing evidence of conditions that arose after balance sheet date |
| **Financial Statements Issued** | Statements widely distributed to shareholders and other users |
| **Financial Statements Available to Be Issued** | Completed with all information available and ready for issuance |

---

## Types of Subsequent Events

### Type I—Recognized Subsequent Events

**Definition:** Events that provide additional evidence about conditions that **existed** at the balance sheet date.

**Treatment:** Recognize in the financial statements (adjust amounts)

| Example | Balance Sheet Condition | Subsequent Event |
|---------|------------------------|------------------|
| Uncollectible receivable | Customer financial difficulty | Bankruptcy filing |
| Litigation settlement | Lawsuit pending at year-end | Settlement agreed |
| Inventory valuation | Lower NRV suspected | Sales confirm loss |
| Asset impairment | Impairment indicators | Subsequent sale confirms value |

### Type II—Nonrecognized Subsequent Events

**Definition:** Events that provide evidence about conditions that **arose** after the balance sheet date.

**Treatment:** Do not adjust financial statements; disclose if material

| Example | Description |
|---------|-------------|
| Business combination | Acquisition completed after year-end |
| Issuance of debt/equity | New financing after year-end |
| Major casualty loss | Fire, flood, or other loss after year-end |
| Changes in fair value | Market changes after year-end |
| Dividends declared | Board action after year-end |
| Litigation filed | New lawsuit after year-end |

---

## Subsequent Events Period

### Determining the End Date

| Entity Type | Period Ends When |
|-------------|------------------|
| **SEC filers** | Financial statements **issued** |
| **Non-SEC filers** | Financial statements **issued** or **available to be issued** |
| **Conduit bond obligors** | Financial statements **available to be issued** |

### "Issued" vs. "Available to Be Issued"

| Status | Definition |
|--------|------------|
| **Issued** | Widely distributed to shareholders, other users, regulators, or filed with SEC |
| **Available to be issued** | Financial statements completed—all information reflected and authorized for issuance |

**Timeline Example:**
```
December 31       March 1           March 15          March 20
Balance Sheet     Audit Complete    Board Approval    Distribution
Date              & Ready                             to Users
     |                |                  |                |
     |<----- Subsequent Events Period (SEC filer) ------>|
     |<-- Period (Non-SEC) -->|
              (if available to be issued March 1)
```

## Recognition and Measurement

### Type I Events—Adjusting

**Process:**
1. Identify conditions existing at balance sheet date
2. Determine if subsequent event provides additional evidence
3. Adjust financial statement amounts
4. May require additional disclosures

**Example—Bad Debt:**

**Facts:**
- December 31: Customer owes $100,000; some doubt about collection
- January 15: Customer files bankruptcy; $80,000 uncollectible

**Analysis:** Bankruptcy provides evidence of condition (financial difficulty) existing at December 31.

**Adjustment:**
```
Dr. Bad Debt Expense                  $80,000
    Cr. Allowance for Doubtful Accounts       $80,000
(Adjust allowance based on subsequent bankruptcy)
```

---

### Type II Events—Disclosing

**Process:**
1. Identify events arising after balance sheet date
2. Evaluate materiality and significance
3. Disclose nature and financial effect (if determinable)
4. Do NOT adjust financial statement amounts

**Example—Building Fire:**

**Facts:**
- December 31: Balance sheet date
- January 20: Major fire destroys warehouse (FMV: $2,000,000)
- Insurance coverage: $1,500,000

**Analysis:** Fire occurred after year-end; condition did not exist at December 31.

**Disclosure Only:**
```
NOTE X: SUBSEQUENT EVENT

On January 20, 20X2, the Company's main distribution warehouse was
destroyed by fire. The warehouse had a carrying value of $1,800,000
at December 31, 20X1. The Company maintains property insurance with
coverage of $1,500,000. Management is currently assessing the full
impact of the loss, including business interruption effects. The
Company expects to recognize a loss of approximately $300,000 in
20X2 related to the uninsured portion.
```

## Specific Situations

### Litigation Settlements

| Timing | Treatment |
|--------|-----------|
| **Lawsuit existed at year-end; settled after** | Type I—Adjust if provides evidence of year-end condition |
| **New lawsuit filed after year-end** | Type II—Disclose only |
| **Settlement amount different from accrual** | Evaluate whether difference is new information or changed condition |

### Business Combinations

| Timing | Treatment |
|--------|-----------|
| **Acquisition agreed at year-end; closed after** | Evaluate significance; may be Type II |
| **Acquisition negotiated/closed after year-end** | Type II—Disclose |

### Debt and Equity Transactions

| Event | Treatment |
|-------|-----------|
| **Debt covenant violation cured after year-end** | Generally does not change classification |
| **New debt/equity issued** | Type II—Disclose |
| **Debt refinanced (for classification purposes)** | May affect classification per ASC 470 |

### Dividend Declarations

| Event | Treatment |
|-------|-----------|
| **Cash dividend declared after year-end** | Type II—Disclose per share amount |
| **Stock dividend/split after year-end** | Retroactive restatement of EPS; disclose |

### Going Concern Considerations

| Situation | Treatment |
|-----------|-----------|
| **Events alleviate going concern doubt** | May affect going concern conclusion |
| **Events create going concern doubt** | Evaluate and disclose per ASC 205-40 |

## Practical Examples

### Example 1: Recognized Event—Litigation Settlement

**Facts:**
- December 31, 20X1: Lawsuit pending; loss contingency accrued at $500,000
- February 10, 20X2: Settlement agreed at $750,000
- Financial statements issued: March 15, 20X2

**Analysis:**
- Lawsuit existed at December 31 (condition existed)
- Settlement provides evidence of year-end liability amount
- Type I event—adjust

**Adjustment:**
```
Dr. Litigation Expense                $250,000
    Cr. Litigation Liability                  $250,000
(Adjust accrual from $500,000 to $750,000)
```

---

### Example 2: Nonrecognized Event—Major Acquisition

**Facts:**
- December 31, 20X1: Balance sheet date
- January 25, 20X2: Acquired competitor for $5,000,000
- Financial statements available to be issued: February 28, 20X2

**Analysis:**
- Acquisition occurred after year-end
- Condition did not exist at December 31
- Type II event—disclose only

**Disclosure:**
```
NOTE X: SUBSEQUENT EVENT

On January 25, 20X2, the Company completed the acquisition of
Competitor, Inc. for total consideration of $5,000,000, consisting
of $3,000,000 in cash and $2,000,000 in common stock (100,000
shares). The acquisition was accounted for as a business combination
under ASC 805. Preliminary purchase price allocation is in process
and will be completed in the first quarter of 20X2.
```

---

### Example 3: Type I vs. Type II Judgment

**Scenario A—Customer Bankruptcy (Type I):**
- Customer was experiencing financial difficulty at year-end
- Filed bankruptcy January 15
- **Treatment:** Adjust allowance (evidence of existing condition)

**Scenario B—Customer Loss of Major Contract (Type II):**
- Customer was financially healthy at year-end
- Lost major contract January 15, leading to payment issues
- **Treatment:** Disclose if material (new condition)

---

### Example 4: Inventory Valuation

**Facts:**
- December 31: Inventory on hand at cost: $1,000,000
- January 10: Sold entire inventory for $850,000
- Market price decline occurred after year-end due to new competitor

**Analysis:**
Was the decline in value a condition existing at December 31?
- If market was already weakening: Type I—adjust
- If new competitor caused decline: Type II—disclose

**If Type I:**
```
Dr. Cost of Goods Sold (or Loss)      $150,000
    Cr. Inventory                              $150,000
```

**If Type II:** Disclose nature and amount of subsequent decline

## SEC Registrant Considerations

### Extended Disclosure Period

SEC registrants evaluate subsequent events through the date financial statements are **issued** (filed with SEC).

### SAB 103 Considerations

- Interim events affecting full year financial statements
- Events between quarter-end and filing
- Material subsequent events require disclosure

### Form 8-K Requirements

Certain subsequent events require immediate reporting on Form 8-K, separate from financial statement disclosure.

## Private Company Considerations

### "Available to Be Issued" Standard

Private companies typically use "available to be issued" date:
- Financial statements complete
- All necessary approvals obtained
- Ready for distribution

### Documentation

| Document | Purpose |
|----------|---------|
| **Board minutes** | Evidence of approval date |
| **Management representation** | Confirm subsequent events evaluation |
| **Subsequent events checklist** | Systematic evaluation |

### Common Private Company Subsequent Events

| Event | Frequency | Impact |
|-------|-----------|--------|
| Owner distributions | Common | Disclose large amounts |
| New financing | Common | Disclose terms |
| Related party changes | Moderate | Disclose if significant |
| Major contracts won/lost | Varies | Evaluate impact |

## Reissuance Considerations

### Dual Dating

When financial statements are reissued:

**Option 1—Dual Date:**
```
Report of Independent Auditors
March 15, 20X2, except for Note X, as to which the date is April 5, 20X2
```

**Option 2—New Date:**
- Extend all subsequent events procedures to new date
- Date report as of new date

### What Triggers Reissuance

- Material error discovery
- Subsequent event requiring disclosure
- Additional information requested by user

## Common Audit Issues

### Identification

| Issue | Audit Procedure |
|-------|-----------------|
| **Undisclosed events** | Inquire of management; review board minutes |
| **Cutoff errors** | Test transactions near year-end |
| **Legal matters** | Attorney letter confirmation |
| **Significant judgments** | Challenge Type I vs. Type II conclusions |

### Documentation Requirements

Auditors should document:
- Subsequent events procedures performed
- Date procedures performed through
- Management representations obtained
- Conclusions reached

### Representation Letter

**Include confirmations that:**
- All subsequent events have been identified
- Financial statements reflect all adjusting events
- All nonrecognized events have been disclosed

## Disclosure Requirements

### Required Disclosures

| Item | Requirement |
|------|-------------|
| **Date through which evaluated** | Required for all entities |
| **Basis for date** | "Issued" or "available to be issued" |
| **Nature of nonrecognized events** | Description of event |
| **Financial effect** | Estimate if determinable |

### Example Disclosure—Date Evaluated

```
NOTE X: SUBSEQUENT EVENTS

The Company has evaluated subsequent events through March 15, 20X2,
the date on which the financial statements were available to be
issued [or: were issued], and determined that no events occurred
that require disclosure, except as noted below:

[Description of any Type II events requiring disclosure]
```

## Subsequent Events Checklist

### Type I Indicators (May Require Adjustment)

- [ ] Collection of receivables significantly different from expected
- [ ] Settlement of litigation for amount different from accrual
- [ ] Sale of investments below carrying value
- [ ] Inventory sold below cost
- [ ] Additional information about estimates (warranties, contingencies)

### Type II Indicators (May Require Disclosure)

- [ ] Business combination or disposal
- [ ] Debt or equity issuance
- [ ] Major asset purchases or sales
- [ ] Restructuring initiatives
- [ ] Loss from casualty (fire, flood, etc.)
- [ ] Significant changes in fair value
- [ ] New litigation
- [ ] Going concern events
- [ ] Regulatory actions
