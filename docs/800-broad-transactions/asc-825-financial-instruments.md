# ASC 825: Financial Instruments

> Comprehensive guidance on financial instrument recognition, measurement, and disclosure—including the fair value option.

## Overview

ASC 825 provides guidance on financial instruments, including the fair value option for measuring certain financial assets and liabilities. It also establishes extensive disclosure requirements about fair value and provides guidance on concentrations of credit risk. This topic is central to understanding how entities account for and disclose their financial instrument portfolios.

**Core Principle:**
> "Financial instruments are contracts that create both a financial asset for one entity and a financial liability or equity instrument for another. Entities may elect fair value measurement for eligible items, with changes recognized in earnings."

---

## Scope

### Applies To:
- Fair value option elections
- Financial instrument disclosures
- Credit risk concentrations
- Recognition and measurement guidance for instruments not covered elsewhere

### Does NOT Apply To (Covered by Other Topics):
- Investments in debt securities (ASC 320)
- Investments in equity securities (ASC 321)
- Derivatives and hedging (ASC 815)
- Leases (ASC 842)
- Share-based payments (ASC 718)
- Pensions and OPEB (ASC 715)

---

## Key Definitions

| Term | Definition |
|------|------------|
| **Financial Instrument** | Cash, ownership interest in entity, or contract conveying right/obligation to deliver/receive cash or other financial instruments |
| **Financial Asset** | Cash, equity instrument of another entity, contractual right to receive cash/financial asset |
| **Financial Liability** | Contractual obligation to deliver cash or financial asset to another entity |
| **Fair Value Option (FVO)** | Irrevocable election to measure eligible items at fair value through earnings |
| **Hybrid Instrument** | Contract with embedded derivative that may require bifurcation |

---

## The Fair Value Option (FVO)

### Overview

The fair value option allows entities to elect fair value measurement for eligible financial instruments, with changes in fair value recognized in earnings. This election:
- Is irrevocable
- Must be made at specific election dates
- Is applied instrument-by-instrument

### Eligible Items

| Category | Eligible | Not Eligible |
|----------|----------|--------------|
| **Recognized financial assets/liabilities** | Most | See exceptions below |
| **Firm commitments** | With financial instruments | Other |
| **Loan commitments** | Written (certain) | See specific guidance |
| **Insurance contracts** | Some | Most |
| **Investments in subsidiaries** | | Not eligible |
| **Pension/OPEB obligations** | | Not eligible |
| **Lease assets/liabilities** | | Not eligible |
| **Demand deposit liabilities** | | Not eligible |

### Election Dates

| Event | Election Timing |
|-------|-----------------|
| **Initial recognition** | Upon initial recognition of item |
| **Business combination** | Date of combination |
| **Consolidation change** | Date entity first consolidated |
| **Specialty accounting** | Exit from specialty accounting |

### Irrevocability

Once elected, the fair value option:
- Cannot be revoked for that instrument
- Continues until derecognition
- Applies to entire instrument (not components)

## Accounting for Fair Value Option Elections

### Initial Recognition

**At Election:**
```
Dr. Financial Asset (at fair value)    $100,000
    Cr. Cash                                     $100,000
```

**If different from transaction price:**
```
Dr. Financial Asset (at fair value)     $95,000
Dr. Loss on Initial Recognition          $5,000
    Cr. Cash                                    $100,000
```

### Subsequent Measurement

**Fair Value Increase:**
```
Dr. Financial Asset                      $8,000
    Cr. Gain on Fair Value Change                $8,000
```

**Fair Value Decrease:**
```
Dr. Loss on Fair Value Change            $5,000
    Cr. Financial Asset                          $5,000
```

### Interest Income/Expense

Even with FVO election, interest income/expense may be:
- Recognized separately using contractual rate, OR
- Included in fair value changes

Disclose the approach used.

## Financial Instrument Categories Summary

### Recognition and Measurement Overview

| Instrument Type | Topic | Initial | Subsequent | Changes In |
|-----------------|-------|---------|------------|------------|
| **Loans receivable** | ASC 310/326 | Fair value | Amortized cost | Earnings (interest) |
| **Loans with FVO** | ASC 825 | Fair value | Fair value | Earnings |
| **HTM debt securities** | ASC 320 | Fair value | Amortized cost | Earnings (interest) |
| **AFS debt securities** | ASC 320 | Fair value | Fair value | OCI (until sold) |
| **Trading securities** | ASC 320 | Fair value | Fair value | Earnings |
| **Equity securities** | ASC 321 | Fair value | Fair value | Earnings |
| **Equity—practicability exception** | ASC 321 | Cost | Cost less impairment | Earnings (impairment) |
| **Derivatives** | ASC 815 | Fair value | Fair value | Earnings or OCI |

## Disclosures—Fair Value of Financial Instruments

### Required Disclosures

**For all financial instruments:**

| Disclosure | Content |
|------------|---------|
| **Fair value** | Fair value of all financial instruments |
| **Carrying amount** | Book value for comparison |
| **Level in hierarchy** | Level 1, 2, or 3 (per ASC 820) |
| **Methods and assumptions** | How fair value determined |
| **Changes in methods** | Explanation if methods changed |

### Disclosure Exemptions

Certain entities may have reduced requirements:
- Nonpublic entities have disclosure alternatives
- Trade receivables/payables at carrying amount if approximately fair value

## Fair Value Option—Specific Disclosures

### For Items with FVO Elected

| Disclosure | Requirement |
|------------|-------------|
| **Management's reasons** | Why fair value option elected |
| **Carrying amount by category** | Similar items grouped |
| **Gains and losses** | Amount and income statement line |
| **Instrument-specific credit risk** | Changes due to own credit |
| **Interest income/expense** | How recognized |
| **Dividends** | For equity instruments |
| **Upfront costs/fees** | How recognized |

### Instrument-Specific Credit Risk (Liabilities)

For liabilities measured under FVO:
- Disclose changes in fair value attributable to instrument-specific credit risk
- Present in OCI (not earnings) per ASU 2016-01

**Journal Entry:**
```
Dr. Financial Liability                  $10,000
    Cr. OCI—Credit Risk Change                   $7,000
    Cr. Gain on Fair Value Change                $3,000
(Fair value decrease due to credit risk goes to OCI)
```

## Credit Risk Concentration Disclosures

### General Requirements

Entities must disclose concentrations of credit risk arising from:
- Financial instruments (individual or group)
- Geographic areas
- Industries
- Counterparties

### Required Elements

| Element | Disclosure |
|---------|------------|
| **Nature of concentration** | What creates the risk |
| **Maximum exposure** | Amount at risk |
| **Collateral** | If any reduces risk |
| **Policies** | Risk management approaches |

### Examples of Concentrations

- Large percentage of receivables from single customer
- Loans concentrated in single industry
- Derivative exposures with single counterparty
- Geographic concentration (e.g., single state)

## Offsetting Financial Assets and Liabilities

### General Rule (ASC 210-20)

Offsetting is permitted only when:
1. Right of setoff exists
2. Intent to settle net (or simultaneously)

### Master Netting Arrangements

**Disclosure Requirements:**

| Element | Disclosure |
|---------|------------|
| **Gross amounts** | Assets and liabilities before netting |
| **Amounts offset** | Under ASC 210-20 |
| **Net amounts** | On balance sheet |
| **Amounts subject to netting** | Not offset on balance sheet |
| **Collateral** | Received and pledged |
| **Net exposure** | After all adjustments |

## Practical Examples

### Example 1: Fair Value Option Election for Loan

**Facts:**
- Bank originates $1,000,000 loan
- Market rate at origination: 6%
- Contractual rate: 5.5%
- Fair value at origination: $975,000
- Elects fair value option

**Initial Recognition:**
```
Dr. Loan Receivable (at FV)           $975,000
Dr. Day 1 Loss                         $25,000
    Cr. Cash                                   $1,000,000
```

**Year-End Fair Value: $990,000:**
```
Dr. Loan Receivable                    $15,000
    Cr. Gain on Fair Value Change              $15,000

Dr. Cash                               $55,000
    Cr. Interest Income                        $55,000
(Interest at contractual rate, recorded separately)
```

---

### Example 2: Liability with Credit Risk Change

**Facts:**
- Issued $500,000 bond, elected FVO
- Fair value decreased to $450,000
- $35,000 of decrease due to worsened credit risk
- $15,000 due to interest rate changes

**Journal Entry:**
```
Dr. Bonds Payable                      $50,000
    Cr. OCI—Instrument-Specific Credit Risk    $35,000
    Cr. Gain on Fair Value Change              $15,000
```

**Balance Sheet Impact:**
- Bonds payable: $450,000 (fair value)
- AOCI increased by $35,000 (credit component)
- Income statement: $15,000 gain

---

### Example 3: Concentration Disclosure

**Sample Disclosure:**
```
CREDIT RISK CONCENTRATION

The Company's accounts receivable are concentrated among customers
in the oil and gas industry (approximately 85% of receivables at
December 31, 20X1). The Company's maximum credit risk exposure
related to these receivables is $4.2 million. The Company mitigates
this risk through credit insurance covering 70% of the balance and
regular monitoring of customer credit quality.

Additionally, two customers represented 45% and 22% of total
receivables, respectively. The Company requires letters of credit
from customers exceeding $500,000 in outstanding balances.
```

## Hybrid Financial Instruments

### Overview

Hybrid instruments contain:
- Host contract (debt or equity)
- Embedded derivative(s)

### Bifurcation Requirements

Per ASC 815, bifurcate embedded derivative if:
1. Not clearly and closely related to host
2. Hybrid not measured at fair value through earnings
3. Derivative would require separate accounting

### FVO Election Alternative

Instead of bifurcation:
- Elect FVO for entire hybrid instrument
- Measure entire contract at fair value
- Avoid separation complexity

**Journal Entry (FVO Election):**
```
Dr. Hybrid Instrument (at fair value)  $100,000
    Cr. Cash                                    $100,000
(Entire instrument at fair value; no bifurcation)
```

## Private Company Considerations

### Disclosure Alternatives

Private companies may have reduced disclosure requirements for:
- Fair value of certain items (loans, deposits)
- Level hierarchy for non-recurring fair value
- Certain concentrations

### Practical Expedients

| Area | Expedient |
|------|-----------|
| **Trade receivables** | Carrying amount = fair value (if short-term) |
| **Trade payables** | Carrying amount = fair value (if short-term) |
| **Variable-rate debt** | Carrying amount may approximate fair value |
| **Complexity reduction** | May not elect FVO (fewer disclosures) |

### Common Private Company Issues

1. **Fair value determinations** — May lack readily available data
2. **Valuation specialists** — May be needed for complex instruments
3. **Related party loans** — Must still determine fair value
4. **Loan covenants** — Understand impact of FVO on metrics

## Common Audit Issues

### Fair Value Option

| Issue | Audit Consideration |
|-------|---------------------|
| **Eligibility** | Confirm item qualifies for FVO |
| **Election timing** | Verify made at permitted date |
| **Documentation** | Support for management's reasoning |
| **Consistency** | Applied consistently to similar items |

### Fair Value Measurement

| Issue | Audit Consideration |
|-------|---------------------|
| **Level determination** | Appropriate hierarchy classification |
| **Inputs** | Observable vs. unobservable inputs |
| **Credit risk** | Own credit properly captured |
| **Specialists** | May need valuation expert |

### Disclosure Completeness

- All required disclosures present
- Fair value methodology adequate
- Concentration risks identified
- Sensitivity analysis (if applicable)

## Disclosure Requirements Summary

### All Entities

| Area | Disclosure |
|------|------------|
| **Fair value** | Of all financial instruments |
| **Methods** | Valuation methodology |
| **Concentrations** | Credit risk concentrations |
| **Significant assumptions** | For Level 3 instruments |

### Entities with FVO Elections

| Area | Disclosure |
|------|------------|
| **Reasons** | Why FVO elected |
| **Carrying amounts** | By category |
| **Gains/losses** | From fair value changes |
| **Credit risk changes** | For liabilities |
| **Interest treatment** | How interest recognized |

### Recurring Fair Value

| Area | Disclosure |
|------|------------|
| **Fair value hierarchy** | Level 1, 2, 3 classification |
| **Transfers** | Between levels |
| **Level 3 rollforward** | For significant Level 3 items |
| **Valuation processes** | For Level 3 |
