> **Note:** These templates are for informational purposes only and are intended as starting points. Disclosure requirements vary based on specific facts and circumstances. ---

## Overview

This section provides **sample disclosure templates** for private company financial statements. Each example includes:

- Sample disclosure language
- Placeholder brackets [like this] for company-specific information
- Multiple variations for different scenarios
- References to applicable GAAP standards

## How to Use These Templates

1. **Find the relevant disclosure** in the notes file
2. **Copy the template** to your working papers
3. **Replace bracketed placeholders** with company-specific information
4. **Adjust language** as needed for specific circumstances
5. **Delete inapplicable sections** (e.g., if no related party transactions)

---

## Important Notes

- These templates are for **private company** financial statements
- Adjust disclosures based on your specific reporting framework (full GAAP, tax basis, etc.)
- Some disclosures are **required**, others are **recommended**
- Always verify current GAAP requirements — standards change!
