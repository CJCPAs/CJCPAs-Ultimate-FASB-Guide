# ASC 920: Entertainment—Broadcasters

> Specialized accounting for television and radio broadcasters including license agreements and barter transactions.

## Overview

ASC 920 provides industry-specific guidance for television and radio broadcasters, addressing unique accounting issues including program license agreements, barter transactions, and network affiliation agreements.

> **Core Principle:** Broadcasters must properly account for the costs and revenues associated with program licensing, recognizing that programming rights represent valuable assets that are consumed over the license period.

---

## Scope

### Applies To

- Television broadcasters
- Radio broadcasters
- Cable networks (content aspects)
- Streaming services (certain aspects)
- Network affiliates

### Key Accounting Areas

| Area | Key Issues |

## Program License Agreements

### Asset Recognition

**Recognize program license asset when:**
1. License period has begun
2. Program is available for broadcast
3. Cost is known or determinable

### Measurement

**Initial recognition:** Present value of license payments

**Balance sheet classification:**
- Current: Programs available for broadcast within one year
- Noncurrent: Programs not yet available or beyond one year

### Journal Entry—License Agreement

**License terms:** 3-year license, $1,200,000, payable annually

**At inception (if available immediately):**
```
Dr. Program License Rights              $1,200,000
    Cr. Program License Liability              $1,200,000
```

**Note:** If significant financing component, record at present value

## Program Amortization

### Methods

| Method | When Used |
|--------|-----------|
| **Per-play** | Limited plays, defined runs |
| **Straight-line** | Multiple plays over license period |
| **Accelerated** | Higher value for initial broadcasts |

### Per-Play Amortization

**Example:** Movie license for 5 plays, cost $500,000

| Play | Percentage | Amortization |
|------|------------|--------------|
| 1st | 50% | $250,000 |
| 2nd | 25% | $125,000 |
| 3rd | 12% | $60,000 |
| 4th | 8% | $40,000 |
| 5th | 5% | $25,000 |

**Journal Entry—First broadcast:**
```
Dr. Program Amortization Expense        $250,000
    Cr. Accumulated Amortization               $250,000
```

### Series/Syndication

**Off-network series:** Amortize based on estimated revenue or viewership

```
Amortization Rate = Estimated Revenue per Episode / Total Estimated Revenue
```

## Barter Transactions

### Definition

Exchange of advertising time for programming, merchandise, or services.

### Accounting Treatment

**General rule:** Record at fair value of advertising time surrendered

**When FV determinable:**
```
Dr. Program/Merchandise (at FV)          $50,000
    Cr. Barter Revenue                         $50,000
```

**When FV not determinable:** Use fair value of item received

### Barter Revenue Recognition

**Recognize when:**
- Advertising is broadcast
- Based on fair value of time given up

### Example—Program Barter

**Terms:** Receive syndicated program in exchange for 30% of advertising time

**If 30% of time worth $100,000:**
```
Receive program:
Dr. Program Rights—Barter               $100,000
    Cr. Deferred Barter Revenue                $100,000

When advertising airs:
Dr. Deferred Barter Revenue             $100,000
    Cr. Barter Revenue                         $100,000

Amortize program:
Dr. Program Expense                     $100,000
    Cr. Program Rights—Barter                  $100,000
```

## Network Affiliation

### Types of Arrangements

| Arrangement | Description |
|-------------|-------------|
| **Affiliation agreement** | Local station carries network programming |
| **Network compensation** | Payment to affiliate for carrying programs |
| **Reverse compensation** | Affiliate pays network |

### Network Compensation Revenue

**Recognize when:**
- Earned (programming broadcast)
- Amount determinable

```
Dr. Network Compensation Receivable      $50,000
    Cr. Network Affiliation Revenue            $50,000
```

### Retransmission Fees

**Fees from cable/satellite operators:**
- Recognize over the service period
- Based on subscriber counts

## Advertising Revenue

### Recognition Principles

**Recognize when advertisements are broadcast:**

```
Dr. Accounts Receivable                 $100,000
    Cr. Advertising Revenue                    $100,000
```

### Agency Commissions

**Gross vs. Net:**
- Generally report gross revenue
- Deduct agency commission as expense

**Or net if agency is principal:**
```
Dr. Accounts Receivable (net)            $85,000
Dr. Agency Commission                    $15,000
    Cr. Advertising Revenue                    $100,000
```

### Make-Good Obligations

When audience guarantees not met:
- **Future spots:** Deferred revenue until provided
- **Cash refunds:** Reduce revenue

## Sports Broadcasting Rights

### Multi-Year Agreements

**Recognition:** Over the period rights are held/events occur

**Example—3-year sports package:**
```
Total cost: $30,000,000
Events per year: 50, 50, 50

Per-event cost: $200,000

As events broadcast:
Dr. Sports Programming Expense          $200,000
    Cr. Sports Rights Asset                    $200,000
```

### Advance Payments

```
Dr. Prepaid Sports Rights              $10,000,000
    Cr. Cash                                  $10,000,000
```

## Impairment

### Program License Impairment

Test for impairment when indicators present:
- Program cancelled or delayed
- Ratings significantly below expectations
- Market conditions change

**Impairment test:** Compare carrying amount to fair value

**Journal Entry—Impairment:**
```
Dr. Impairment Loss—Program Rights      $100,000
    Cr. Program License Rights                 $100,000
```

### Indicators of Impairment

| Indicator | Consideration |
|-----------|---------------|
| Ratings decline | Lower than expected viewership |
| Advertiser pullout | Reduced revenue potential |
| Program changes | Cast departures, content issues |
| Competitive pressure | New competing programming |

## Digital and Streaming

### Modern Considerations

| Topic | Treatment |
|-------|-----------|
| **Streaming rights** | Similar to broadcast licenses |
| **Digital advertising** | Same principles, impression-based |
| **Content libraries** | Capitalize, amortize over useful life |
| **Original content** | Capitalize if criteria met |

### Multiple Platform Rights

When rights span multiple platforms:
- Allocate cost based on relative value
- Amortize each component separately

## Disclosure Requirements

### Required Disclosures

1. **Program rights** accounting policy
2. **Amortization** methods used
3. **Barter transactions** policy and amounts
4. **Contractual commitments** for programming

### Example Disclosure

> **Program Rights:** The Company records program rights when the license period begins and the programs are available for broadcast. Program costs are amortized based on the expected pattern of use, typically on a per-play or straight-line basis over the license period. Barter transactions are recorded at the fair value of advertising time exchanged. For the year ended December 31, 20XX, barter revenue and expense were each approximately $X million.

## Common Audit Issues

1. **Asset recognition timing** — Programs not yet available
2. **Amortization method** — Inappropriate method selection
3. **Barter fair value** — Unsupported valuations
4. **Impairment** — Failure to test when indicators present
5. **Contract commitments** — Incomplete disclosure
6. **Revenue cutoff** — Advertising recognized prematurely
7. **License liability** — Present value not applied
